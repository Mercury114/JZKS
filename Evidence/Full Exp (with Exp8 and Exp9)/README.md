# Full Exp (with Exp8 and Exp9)

这是课程实验主线资料包。`engineering/Exp7` 是第五章前的流水线基线；`engineering/Exp8` 与 `engineering/Exp9` 分别保留 Vivado 工程入口、RTL、约束、IP 输入、RAM 初始化文件、参考 Trace、实现报告和 bitstream。`source/Exp9_源码_v文件` 是便于报告模型学习的源码清单；`evidence/Exp8`、`evidence/Exp9` 单独保存波形配置、波形相关日志和 Trace；`team-regression` 保存前面各 Exp 的整机/教师回归输出。

课程要求的证据与扩展证据分开理解：工程目录证明课程实验产物，`D-cache` 目录证明个人扩展，`Important/Full-Exp_PASS` 只摘录最适合答辩引用的 PASS 输出。Exp8/Exp9 的大 `.wdb` 已在 `waveforms/` 无损分片，恢复方式见上级 `Evidence/README.md`。
